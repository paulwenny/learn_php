# REPOSITORY lEARN PHP

Repositori learn_php merupakan repo yang digunakan untuk keperluan belajar dasar-dasar pemrograman PHP.

## Branch

1. main

   - branch main ini akan berisikan projek hasil dari pembelajaran dasar-dasar pemrograman PHP

2. php_basic-wpu
   - berisikan materi-materi dasar pemrograman php dari sumber chanel youtube WPU

3. php_oop-wpu
   - berisikan materi-materi dasar pemrograman berorientasi objek (OOP) dengan menggunakan bahasa pemrograman php, dari sumber chanel youtube WPU

4. php_mvc-wpu
   - berisikan materi-materi dasar php dengan menerapkan konsep model view controler (MVC) dengan sumber chanel youtube WPU
